# VOID Shared Memory — Demo Projects

Demonstration projects for VOID Shared Memory (Header V2).

Each demo contains:

- An Ableton Live project
- A TouchDesigner network
- Embedded Max for Live devices (Collect & Save applied)

The projects are self-contained and designed for quick validation of the pipeline.

---

## Included Demos

- `01_sync`
- `02_freqAnalysis`
- `03_8notes`
- `04_8params`
- `05_envFollower`
- `06_receiver`

Each folder demonstrates a specific control-rate exchange use case between Ableton Live and TouchDesigner.

---

## Structure

Inside each demo:

- Live Project (`.als`)
- TouchDesigner file (`.toe`)
- Embedded Max for Live devices
- No external dependency required

Devices are frozen and included directly in the Live project.

---

## Purpose

These demos are intentionally minimal.

They are meant to:

- Validate shared memory connectivity
- Verify channel mapping
- Confirm Header V2 compliance
- Test real-time parameter exchange

They are not artistic showcase projects.

---

## Requirements

- Ableton Live
- TouchDesigner
- macOS (Apple Silicon recommended)
